# Star Wars: Empire at War - Vanilla+ Modernization

A lightweight mod plan that refreshes **Star Wars: Empire at War** while keeping its vanilla factions, units, and campaign flow. The goals are higher-fidelity visuals, modern quality-of-life tweaks, and gentle balance clean-up without altering the game’s core identity.

## Quick start
1. Read `docs/mod_concept.md` for the full Vanilla+ feature list, art-upgrade targets, and XML tuning checklist.
2. Follow the suggested `Data/` folder structure in that document when creating the mod package (XML, Art, Audio, Scripts).
3. Prioritize texture upscales and camera tuning first; gameplay tweaks should preserve vanilla roles and counters.
4. Apply the included `Data/XML/GameConstants.xml` overrides to enable the doubled land unit cap, expanded space caps, and raised camera ceilings.

## Status
This repository currently contains documentation and production notes alongside an initial `GameConstants.xml` override. Additional game assets, XML definitions, and scripts will be added as they are produced.
